# Basic Calculator

A fully self-contained **Basic Calculator** static web page — no backend, no server, no external dependencies.

[![Live Demo](https://img.shields.io/badge/demo-open%20index__fixed.html-blue)](index_fixed.html)

---

## Features

- Four arithmetic operations: **+, −, ×, ÷**
- Decimal point input (one per operand)
- **Clear (C)** and **Backspace (⌫)** controls
- Division-by-zero error handling (displays `Error`)
- Chained operations (left-to-right evaluation)
- Up to 10 significant digits; scientific notation for very large/small numbers
- Responsive layout — works on mobile (320px) and desktop (up to 2560px)
- Full **keyboard support**: `0–9`, `+`, `-`, `*`, `/`, `Enter`, `Backspace`, `Escape`
- WCAG 2.1 accessible: `aria-label`, `aria-live`, `:focus-visible` focus ring

## Usage

1. **Double-click** `index_fixed.html` to open in your browser — no server needed.
2. Or serve from any static host (GitHub Pages, S3, Nginx).

> When hosted on a server, replace the CSP `<meta>` tag with a server-side `Content-Security-Policy` header using a nonce for `script-src` and `style-src`.

## Security Fixes Applied (v1.1)

| ID | Finding | Fix |
|---|---|---|
| SEC-001 | CSP allowed unsafe defaults | Tightened to `default-src 'none'`; added `base-uri` and `form-action` blocks |
| SEC-002 | % button exposed impl status in aria-label | Button disabled; aria-label cleaned |
| QC-001 | Global mutable state | Encapsulated in `Calculator` class |
| QC-003 | Boolean-param anti-pattern in handleEquals | `evaluateExpression()` helper extracted |
| PERF-001 | querySelectorAll on every operator press | NodeList cached at startup |
| PERF-002 | Missing `.flash` CSS rule | Added `.btn.flash` rule |
| SM-001 | Mixed hex color notation | Standardised to 6-digit lowercase |
| SM-002 | `outline: none` on buttons | Replaced with `:focus-visible` outline |
| SM-003–005 | Magic numbers & duplicate literals | Named constants + single `OP_SYMBOLS` object |
